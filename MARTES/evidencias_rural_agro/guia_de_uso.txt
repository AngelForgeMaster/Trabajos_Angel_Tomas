---

### 🛠️ Paso a paso para actualizar GitHub:

1. **Abrir la terminal en tu carpeta:** Paso 1.
Abre Visual Studio Code en la carpeta `Trabajos_Angel_Tomas` y asegúrate de estar en la **Terminal** (puedes usar el atajo `Ctrl + Shift + ~` si no la ves).


2. **Preparar los nuevos archivos y cambios:** Paso 2.
Ejecuta el siguiente comando para poner todos los archivos modificados o creados en la lista de espera:

```bash
git add .

```


3. **Guardar una nota del avance (Commit):** Paso 3.
Crea un punto de guardado escribiendo un mensaje breve que describa lo que agregaste o modificaste hoy (por ejemplo: *'Actualización de evidencias del martes'*):

```bash
git commit -m "Nuevos avances y trabajos agregados"

```


4. **Subir los cambios a GitHub:** Paso 4.
Envía las novedades a tu repositorio en la nube:

```bash
git push origin main

```


---

### 💡 ¿Cómo confirmar que todo se subió bien?

Una vez ejecutado el `git push`, puedes escribir este comando rápido para verificar que el entorno quedó completamente limpio y actualizado:

```bash
git status

```

Si la terminal responde **`nothing to commit, working tree clean`**, ¡significa que tus cambios ya están totalmente respaldados en GitHub y visibles para tus compañeros!

¿Te apareció algún mensaje o alerta al ejecutar los comandos? Escríbeme si necesitas confirmar algo.
